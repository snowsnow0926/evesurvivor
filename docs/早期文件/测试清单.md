# 测试清单 — MVP v0.1

> 测试前准备：用 Godot 4.6.x 打开项目，按 F6 运行

---

## P0 — 核心功能（必须通过）

### P0.1 移动与转向
- [ ] WASD 四方向移动是否正常
- [ ] 移动时舰船朝向是否平滑跟随速度方向（无瞬移）
- [ ] 舰船是否被限制在屏幕边界内

### P0.2 自动索敌与射击
- [ ] 导弹是否每 0.8s 自动发射（不按键）
- [ ] 导弹是否飞向最近敌人
- [ ] 导弹命中敌人后是否消失
- [ ] 敌人被击杀后是否掉落经验球
- [ ] 无敌人时是否不发射导弹

### P0.3 伤害与护盾
- [ ] 敌人接触玩家是否扣血
- [ ] 护盾是否优先于 HP 承受伤害
- [ ] 护盾是否持续回充（每秒恢复）
- [ ] 暂停期间护盾是否停止回充
- [ ] HP 归零时是否弹出结算界面

### P0.4 经验与升级
- [ ] 拾取经验球后经验条是否增长
- [ ] 经验满时是否弹出三选一升级界面
- [ ] 选择升级后效果是否生效（刷新属性）
- [ ] 升级期间游戏是否冻结
- [ ] 升级选择完成后游戏是否继续

### P0.5 难度递增
- [ ] 每击杀 20 只敌人后敌人生成是否加快
- [ ] 后期敌人血量是否变高（能抗更多导弹）

## P1 — 系统完整性

### P1.1 暂停与撤离
- [ ] ESC 是否打开暂停菜单
- [ ] 暂停菜单点击"继续"是否恢复游戏
- [ ] 暂停菜单点击"撤离并结算"是否进入结算界面
- [ ] 撤离结算是否正确获得 100% 资源

### P1.2 结算与维修
- [ ] 阵亡结算界面是否显示正确击杀数/等级
- [ ] 阵亡结算是否只获得 50% 资源
- [ ] 舰船损坏时维修按钮是否可用
- [ ] 维修后是否能重新开始新游戏
- [ ] 星币不足时维修按钮是否禁用

### P1.3 主菜单
- [ ] 主菜单是否显示当前星币/矿物
- [ ] 舰船损坏时是否显示红色"损坏"状态
- [ ] 舰船完好时是否显示绿色"完好"状态
- [ ] 损坏时维修按钮是否正常扣费修复
- [ ] 修复后开始游戏是否正常

### P1.4 场景切换
- [ ] 主菜单 → 点击开始 → 进入游戏场景
- [ ] 游戏结束 → 返回主菜单 → 星币/矿物是否保留
- [ ] 场景切换是否有报错

## P2 — 升级效果验证

> 测试方法：反复升级同一选项直到最大次数，确认效果叠加

| 升级 | 预期效果 | 测试 |
|------|----------|------|
| 射速提升 | 发射间隔减少 10%/次 | 叠加 3 次后发射间隔约 0.8×0.9³ ≈ 0.58s |
| 伤害强化 | 伤害增加 20%/次 | 叠加 3 次后单发伤害约 15×1.2³ ≈ 26 |
| 护盾上限 | 盾上限 +30 | 叠加 3 次后盾上限约 50+90=140 |
| 移动加速 | 移速增加 10%/次 | 叠加 3 次后移速约 320×1.1³ ≈ 425 |
| 弹幕扩散 | 2发，偏移6度 | 叠加 2 次后应发射 3 发 |
| 生命回复 | HP +2/s | 叠加 3 次后每秒回复约 6 HP |

## P3 — 边界情况

- [ ] 0 个敌人存在时发射逻辑是否不报错
- [ ] 大量敌人同时存在（100+）时是否流畅
- [ ] 经验球 30 秒后是否自动消失
- [ ] 导弹超出射程后是否消失（3 秒上限）
- [ ] 快速连续升级时 UI 是否正常响应
- [ ] 结算界面反复点击按钮是否有异常
- [ ] 舰船损坏状态下再次阵亡是否正常

---

## 已知限制（MVP 范围）

- 所有精灵为占位色块，无正式美术资源
- 无音效和粒子特效
- 无存档系统（GameState 仅运行时有效）
- 无闯关模式
