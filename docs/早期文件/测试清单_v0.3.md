# 测试清单 — v0.3 双武器系统

> 测试前准备：用 Godot 4.6.x 打开项目，按 F6 运行。游戏开始前选择种族（人类=导弹，兽人=加农炮）。

---

## P0 — 核心功能（必须通过）

### P0.1 武器加载与显示
- [ ] 选择人类后，HUD 顶部是否显示武器槽（M=导弹）
- [ ] 选择兽人后，HUD 顶部是否显示武器槽（C=加农炮）
- [ ] 武器槽是否显示武器名称

### P0.2 自动射击
- [ ] 人类：导弹是否按间隔自动发射（0.8s），朝向最近敌人
- [ ] 兽人：加农炮炮弹是否按间隔自动发射（1.2s），朝向最近敌人
- [ ] 无敌人时是否不发射（控制台无报错）
- [ ] 武器射击时控制台是否无报错

### P0.3 双武器独立冷却
- [ ] 单武器状态下，另一槽位为空，不影响射击
- [ ] 如果获得第二武器后（暂未实装获得新武器，但可手动验证逻辑），两个武器是否各自独立计时

### P0.4 Q 键切换
- [ ] 按 Q 键后控制台是否打印切换日志
- [ ] 单武器状态下按 Q 是否打印"Only one weapon equipped"
- [ ] 切换后 HUD 高亮边框是否切换到对应槽位

### P0.5 升级池包含武器专属升级
- [ ] 弹出升级选项时，是否有几率出现"导弹速射""制导增强""弹头强化"（导弹专属）
- [ ] 是否有机会出现"穿透强化""炮管冷却""高爆弹药"（加农炮专属）

### P0.6 加农炮穿透
- [ ] 兽人使用加农炮时，炮弹是否击中第一个敌人后消失（默认穿透=1）
- [ ] 选择"穿透强化"升级后，穿透数是否增加（可在控制台打印验证 hit_count）

---

## P1 — 武器专属升级效果

> 测试方法：反复升级同一选项直到最大次数，确认效果只作用于对应武器

### 导弹专属升级

| 升级 | ID | 效果 | 最大次数 | 验证方法 |
|------|----|------|----------|----------|
| 导弹速射 | `missile_rf` | missile.fire_interval × 0.8 | 3 | 观察发射间隔是否缩短 |
| 制导增强 | `missile_range` | missile_range += 100 | 2 | 观察更远敌人是否被锁定 |
| 弹头强化 | `missile_dmg` | player_damage × 1.25 | 3 | 观察伤害数字是否变大 |

### 加农炮专属升级

| 升级 | ID | 效果 | 最大次数 | 验证方法 |
|------|----|------|----------|----------|
| 穿透强化 | `cannon_pierce` | cannon_pierce_count += 1 | 2 | 炮弹是否穿过多个敌人 |
| 炮管冷却 | `cannon_rf` | cannon_fire_interval × 0.8 | 3 | 观察发射间隔是否缩短 |
| 高爆弹药 | `cannon_explode` | explode_chance += 0.3 | 2 | 命中后是否触发爆炸特效（需爆炸特效已实现） |

### 通用升级兼容性
- [ ] 选择"射速提升"后，是否同时影响导弹和加农炮的发射间隔
- [ ] 选择"伤害强化"后，两种武器伤害是否都提升

## P2 — HUD 与 UI

### P2.1 武器面板
- [ ] WeaponPanel 是否显示在屏幕顶部中央
- [ ] 武器槽样式（背景色+边框）是否正常
- [ ] 主武器槽边框是否为亮蓝色（高亮）
- [ ] 副武器槽边框是否为暗色（副武器时）
- [ ] 切换武器后高亮是否正确切换
- [ ] 只有一个武器时，WeaponSlot2 是否隐藏
- [ ] 有两个武器时，SwitchHint "[Q]" 是否显示

### P2.2 面板样式
- [ ] 武器槽样式是否与现有 HUD 风格一致（深色半透明背景）
- [ ] 布局是否居中对齐

---

## P3 — 边界情况

- [ ] 升级到所有武器专属升级满级后，是否不再出现于选项中
- [ ] 游戏重新开始后，武器槽、冷却、穿透数是否正确重置
- [ ] 同时选择导弹专属和加农炮专属升级时，两者效果是否互不干扰
- [ ] 种族为兽人时，种族天赋"炮术专精"（+15% 加农炮射速）是否生效

---

## 已知限制（v0.3 范围）

- "获得第二武器"功能未在本版本实装（equip_second_weapon 逻辑已写好，但升级池中无对应升级项）
- 爆炸特效需要 `create_explosion` 方法存在，否则爆炸概率逻辑仅打印日志
- HUD 武器槽切换高亮依赖 `primary_weapon_index` 变量
