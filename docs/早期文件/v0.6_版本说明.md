# EVE Survivor v0.6 版本说明

> 发布日期：2026-04-29

---

## 新增内容

### 基地场景
- **基地中转站**（BaseScene）：作为战斗与主菜单之间的中转站
- 顶部 Header 显示星币/矿物余额
- 左侧导航：维修站 / 装备合成 / 舰船仓库 / 出发战斗 / 返回主菜单
- 新游戏流程：`MainMenu → BaseScene → RaceSelect → GameScene → SettlementScene → BaseScene`

### 维修站
- 按舰船吨位差异化收费（护卫舰500 → 泰坦200000星币）
- 6种舰船列表，显示状态：当前舰船/完好/已损坏
- 替代原 MainMenu 中的统一维修按钮

### 装备合成台
- 6级品质体系：普通 → 精良 → 稀有 → 传奇 → 传说 → 神话
- 合成公式：2件同品质装备 + 星币 = 1件高一级品质装备
- 合成消耗：普通200 / 精良500 / 稀有1500 / 传奇5000 / 传说20000（神话不可合成）
- 库存显示，点击放入合成槽，实时预览结果

### 舰船仓库
- 6种舰船：护卫舰 / 巡洋舰 / 战列巡洋舰 / 战列舰 / 无畏舰 / 泰坦
- 按星币解锁（巡洋舰5000 → 泰坦1000000）
- 解锁后切换当前舰船
- 装备配置结构预留（下版本实现）

---

## 数据结构

- **equipment_data.gd**：装备品质/属性倍率定义
- **ship_data.gd**：6种舰船模板（维修费/解锁费/装备槽位数）
- **GameState 新增字段**：`selected_ship_id`、`unlocked_ships`、`equipment_inventory`、`equipped_weapons`、`equipped_armor`
