## 一、项目总览

| 项目 | 内容 |
|------|------|
| 游戏名称 | EVE Survivor (EVE同人幸存者游戏) |
| 游戏类型 | 2D俯视角类幸存者（Survivor-like）Roguelike |
| 玩法核心 | 在战场中刷怪升级 → 返回基地强化舰船/装备 → 循环挑战 |

## 二、战斗系统 (Combat System)

### 2.1 玩家控制

| 功能 | 状态 | 说明 |
|------|------|------|
| WASD 移动 | ✅ | 平滑方向插值转向（turn_time 0.12s），支持斜向移动 |
| 自动索敌 | ✅ | 每 0.8s 搜索 600px 范围内最近敌人，自动朝向开火 |
| 速度显示 | ✅ | 屏幕左下角 ShipInfoPanel 实时显示移速数值 |
| 种族天赋 | ✅ | 4种族各有专属天赋效果（详见 §七、种族系统） |

### 2.2 武器系统（4种武器 × 5级 = 20种武器）

武器在武器商店购买，支持按吨位过滤（小型/中型/大型/旗舰级）。

| 武器类型 | 弹道特性 | 核心机制 |
|---------|---------|---------|
| **导弹** | 追踪弹道 | 最大追踪3秒，目标死亡自动切换最近目标，超时后直线飞行 |
| **加农炮** | 直线穿透 | 可配置穿透数 + 伤害衰减 + 爆炸概率 |
| **磁轨炮** | 高速单发 | 近距离(400px)、高暴击(35%)、高伤害(30) |
| **激光炮** | 连续光束 | 远距离(700px)、持续2秒、每0.7秒结算伤害 |

#### 武器升级逻辑
- 升级菜单仅显示**已装备武器**的专属升级项（未装备武器的专属升级不出现）
- 权重抽取：高:中:低 = 3:2:1，仅抽取未达上限的升级项
- 3选1选择，支持键盘（↑↓ + Enter）和鼠标点击，ESC跳过

### 2.3 属性系统

| 属性 | 初始值 | 说明 |
|------|--------|------|
| HP上限 | 100 | 受种族和装备影响 |
| 护盾上限 | 50 | 始终优先于HP承受伤害 |
| 护盾回充 | 4/s | 受升级强化 |
| 移动速度 | 320 px/s | 受升级/种族影响 |
| 暴击率 | 5% | 受种族天赋影响 |
| 暴击倍率 | 1.5x | 暴击时伤害数字显示黄色 "!" |
| 闪避率 | 10% | 10%概率减伤，显示 "闪避" |

### 2.4 护盾系统
- 护盾始终回充（4/s，可升级至13.5/s）
- 盾优先于HP承受伤害
- 盾为空时HP直接承受伤害
- 护盾受击时播放受击音效

## 三、敌人系统 (Enemy System)

### 3.1 敌人类型

| 敌人 | HP | 速度 | 行为 | 掉落 |
|------|-----|------|------|------|
| **近战级（Melee）** | 30 | 100 px/s | 追踪玩家，接触伤害10 | 星币10 / 矿物2 |
| **哨兵级（Sentry）** | 20 | 60 px/s | 保持距离，每1.2s发射子弹，子弹伤害8 | 星币14 / 矿物3 |
| **渡鸦级（Raven）** | 15 | 200 px/s | 高速冲刺→0.5s闪烁前摇→100px范围爆炸，伤害25 | 星币18 / 矿物4 |
| **虚空级BOSS（Void）** | 500 | 80 px/s（狂暴120） | 扇形弹幕，60%血进入狂暴模式 | 星币250 / 矿物40 |

### 3.2 敌人生成逻辑
- 屏幕外随机边缘生成（距玩家600~900px）
- 每20击杀：HP×1.1，spawn_interval -0.1s（最低0.8s）
- 生成比例随击杀数动态调整：
  - 0~19杀：近战80% / 哨兵20% / 渡鸦0%
  - 20~49杀：近战60% / 哨兵25% / 渡鸦15%
  - 50+杀（Boss后重置）：近战50% / 哨兵30% / 渡鸦20%
- BOSS在50击杀时出现，击杀后重置难度

### 3.3 敌人视觉效果
- HP血条（ColorRect实现，受伤时动态缩放）
- 受伤闪白特效（modulate插值白闪0.15s）
- 死亡爆炸粒子（CPUParticles2D橙色爆炸扩散）
- BOSS进入狂暴模式后移动速度+50%

### 3.4 BOSS预警
- 击杀45时屏幕上方红色警告横幅，闪烁动画
- BOSS生成时白色闪烁提示

## 四、升级与进度系统

### 4.1 经验系统
- 经验球接触获得，浮动动画 + 飞向玩家
- 经验球30秒后自动消失
- 经验满触发升级（三选一界面，游戏冻结）

### 4.2 连击系统
| 条件 | 倍率 |
|------|------|
| 0~4连击 | 1.0x |
| 5~9连击 | 1.5x |
| 10~19连击 | 2.0x |
| 20~29连击 | 2.5x |
| 30+连击 | 3.0x |

- 3秒无击杀归零
- HUD显示金色 "COMBO!" 提示（连击≥3），≥10颜色加深
- 连击倍率影响星币/矿物掉落

## 五、基地管理系统 (Base Station)

基地作为战斗前后的中转站，提供以下功能模块：

### 5.1 维修站 (RepairStation)
- 按舰船吨位差异化收费（护卫舰500 / 巡洋舰2,000 / 战列巡洋舰5,000 / 战列舰15,000 / 无畏舰50,000 / 泰坦200,000）
- 舰船HP=0时标记为损坏状态，需维修后方可出战

### 5.2 装备合成台 (CraftingTable)
- 放入2件**同品质**装备 + 星币消耗 = 1件**高一级品质**装备
- 6级品质体系：普通 → 优秀 → 精良 → 稀有 → 史诗 → 传说
- 一键合成功能（自动选择可合成的装备对）

### 5.3 武器商店 (ShopUI)
- 标签页切换：武器 / 防御装备
- 吨位过滤：全部 / 小型 / 中型 / 大型 / 旗舰级
- 右侧详情面板显示名称、描述、属性、价格
- 购买/出售功能，出售价为购买价的30%

### 5.4 物品仓库 (WarehouseUI)
- 已装备武器栏（武器槽1~6 + 防御槽）
- 仓库物品网格展示
- 选中物品显示详情（品质色/名称/属性/描述/出售价）
- 装备/卸下/出售操作

### 5.5 造船厂 (ShipyardUI)
- 6种舰船列表（护卫舰/巡洋舰/战列巡洋舰/战列舰/无畏舰/泰坦）
- 舰船升级：解锁武器槽位
- 升级费用：星币 + 低级矿物

### 5.6 星港 (Storage)
- 舰船详情浏览

### 5.7 基地暂停菜单 (BasePauseMenu)
- 返回游戏 / 返回主菜单 / 重置游戏 / 结束游戏

## 七、种族系统 (Race System)

4个可玩种族，各有独特天赋和默认武器：

### 7.1 人类（HUMAN）
- 默认武器：导弹（均衡型）
- 天赋1 **导弹专精**：导弹基础等级 +1
- 天赋2 **精确制导**：导弹索敌范围 +20%
- 属性：HP 100 / 护盾 50 / 移速 320 / 暴击 5%

### 7.2 兽人（ORC）
- 默认武器：加农炮（重火力型）
- 天赋1 **重型装甲**：受到伤害减少 10%
- 天赋2 **炮术专精**：加农炮射速 +15%
- 属性：HP 120 / 护盾 30 / 移速 280 / 暴击 3%

### 7.3 植物（PLANT）
- 默认武器：磁轨炮（高爆发型）
- 天赋1 **磁轨专精**：磁轨炮基础等级 +1
- 天赋2 **光子爆发**：磁轨炮暴击率 +20%
- 属性：HP 100 / 护盾 50 / 移速 320 / 暴击 25%（含天赋）

### 7.4 硅基（SILICON）
- 默认武器：激光炮（持续输出型）
- 天赋1 **激光专精**：激光炮基础等级 +1
- 天赋2 **能量聚焦**：激光宽度 +15%、持续时间 +15%
- 属性：HP 100 / 护盾 50 / 移速 320 / 暴击 5%

| 阵亡 | 50% | 50% |

## 十、存档系统 (Save/Load)

### 10.1 存档机制
- 使用 Godot `ConfigFile` 存储至 `user://game_save.cfg`
- 支持3个存档槽位
- 基地暂停菜单 → 重置游戏 → 确认对话框

### 10.2 存档内容
- 货币（星币、矿物）
- 舰船（已解锁、已升级、损坏状态）
- 装备库存
- 已装备武器/防御（按舰船ID）
- 种族与角色名
- 统计数据（总击杀、总死亡、最高等级）
- 首次运行标记

## 十三、图标渲染系统 (Icon System)

所有游戏角色/敌人/建筑的视觉表现通过SVG矢量路径数据（M/L/Q/Z命令）定义，使用Godot `_draw()` API渲染。

|------|------|------|
| 数据层 | `ship_icon_generator.gd` | JSON加载器、查询接口、IconEntry类 |

| 图鉴预览 | `ship_icon_preview.gd` | 图标网格画廊渲染 |
| 数据文件 | `icon_definitions.json` | 舰船/敌人/建筑图标矢量路径定义 |
| 编辑器场景 | `ShipIconEditor.tscn` | 引擎内矢量图标编辑器 |
| 预览场景 | `ShipIconPreview.tscn` | 图鉴画廊预览 |
