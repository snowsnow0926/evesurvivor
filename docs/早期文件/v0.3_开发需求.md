# v0.3 版本开发需求

> 创建时间：2026-04-29
> 状态：待开发

## 版本目标

在现有的死斗无限模式基础上，增加 2 种新敌人和 1 个 BOSS，使游戏内容更丰富，战斗节奏更有层次。

## 新增内容总览

| 编号 | 内容 | 类型 |
|---|---|---|
| 1 | 远程敌人（哨兵级） | 新敌人 |
| 2 | 自爆敌人（渡鸦级） | 新敌人 |
| 3 | 区域 BOSS（每 5 波出现） | BOSS 战 |
| 4 | 相关升级选项扩展 | 升级池扩充 |
| 5 | BOSS 出场预警 UI | UI 新增 |

## 一、远程敌人：哨兵级（Sentry）

### 设计定位

保持在远处射击的威胁，迫使玩家走位，不能站桩输出。

### 属性

| 属性 | 值 |
|---|---|
| 名称 | 哨兵级 |
| HP | 20 |
| 移动速度 | 60 像素/秒（缓慢移动，保持与玩家距离） |
| 射击间隔 | 1.2 秒 |
| 子弹伤害 | 8 |
| 子弹速度 | 400 像素/秒 |
| 射程 | 500 像素 |
| 索敌范围 | 700 像素 |
| 与玩家保持距离 | 300~400 像素（不贴脸） |
| 攻击冷却 | 1.2 秒 |

### 行为逻辑

1. 从屏幕外随机边缘生成
2. 接近玩家至 350 像素左右停止移动
3. 如果玩家远离，则缓慢跟进
4. 每 1.2 秒朝玩家当前位置发射一枚子弹
5. 子弹为直线飞行，碰到玩家或超出射程后消失

### 子弹（SentryBullet.tscn）

| 属性 | 值 |
|---|---|
| 节点类型 | Area2D |
| 速度 | 400 像素/秒 |
| 伤害 | 8 |
| 碰撞 | 命中玩家扣血后消失 |
| 外观 | 红色小光球（ColorRect 或 Sprite2D 均可，MVP 阶段用形状代替） |

### 掉落

| 物品 | 数量 |
|---|---|
| 经验球 | 1 个 |
| 星币 | +8 |
| 矿物 | +2 |

## 二、自爆敌人：渡鸦级（Raven）

### 设计定位

高速接近玩家，近身后爆炸造成范围伤害，制造紧张感。

### 属性

| 属性 | 值 |
|---|---|
| 名称 | 渡鸦级 |
| HP | 15（容易被击杀） |
| 移动速度 | 200 像素/秒（比普通敌人快一倍） |
| 爆炸范围 | 100 像素（圆形） |
| 爆炸伤害 | 25 |
| 自爆前摇 | 0.5 秒（接近玩家后闪烁，然后爆炸） |
| 爆炸冷却 | 无（炸完就死） |

### 行为逻辑

1. 从屏幕外随机边缘生成
2. 以 200 像素/秒的高速直线冲向玩家
3. 进入玩家周围 30 像素范围内时：
   - 停止移动
   - 开始 0.5 秒自爆倒计时（闪烁效果，modulate 红白交替）
   - 倒计时结束后爆炸
4. 爆炸在 100 像素圆形范围内造成 25 点伤害
5. 如果在自爆前摇期间被击杀，则不会爆炸，直接死亡掉落
6. 爆炸后自身消失

### 特效

- 自爆前：红色闪烁（0.1 秒间隔交替 modulate）
- 爆炸：圆形扩散特效（可用 CPUParticles2D 或 Scale 动画的 ColorRect）

### 掉落

| 物品 | 数量 |
|---|---|
| 经验球 | 1 个 |
| 星币 | +5 |
| 矿物 | +1 |

## 三、区域 BOSS：虚空级（Void）

### 设计定位

每击杀 50 个敌人后，在玩家附近生成一个 BOSS。BOSS 拥有高血量、多种攻击方式，击杀后掉落大量奖励，给玩家一个阶段性的挑战目标。

### 出场条件

- 当前累计击杀数 % 50 == 0
- 每次 BOSS 被击杀后重置计数器，继续下一轮
- BOSS 存活期间，普通敌人继续正常生成（但数量减少到 50%）

### UI 预警

当击杀数达到 45/50 时，屏幕上方显示警告文字：
- "警告：检测到高强度信号……"
- 文字颜色红色，持续显示直到 BOSS 出现
- 击杀数达到 50 时，BOSS 在玩家 500 像素外随机位置生成，同时屏幕闪烁一次（短暂白色覆盖）

### 属性

| 属性 | 值 |
|---|---|
| 名称 | 虚空级 |
| HP | 500 |
| 移动速度 | 80 像素/秒（缓慢追踪玩家） |
| 体型 | 普通敌人的 3 倍大小 |
| 碰撞伤害 | 15（接触，0.5 秒冷却） |
| 特殊技能 | 散射弹幕 |

### 行为逻辑

**普通阶段（HP > 60%）**
- 缓慢朝玩家移动
- 每 1.5 秒朝玩家方向发射 3 枚子弹（呈扇形，间隔 15 度）
- 子弹属性与哨兵级子弹一致

**狂暴阶段（HP ≤ 60%）**
- 移动速度提升至 120 像素/秒
- 射击间隔缩短至 1.0 秒
- 每次发射 5 枚子弹（扇形，间隔 12 度）
- BOSS 颜色变为红色（modulate 变化）

**阵亡阶段（HP ≤ 0）**
- 播放爆炸特效（CPUParticles2D，范围更大，持续时间 1 秒）
- 掉落大量奖励

### 掉落

| 物品 | 数量 |
|---|---|
| 经验球 | 10 个（散落一圈） |
| 星币 | +100 |
| 矿物 | +30 |

### 子弹（BossBullet.tscn）

- 与哨兵子弹共用同一场景，或单独一个场景（如果后续需要不同外观）
- 属性：伤害 10，速度 400 像素/秒

## 四、难度递调整合

由于加入了新敌人，原有的难度递增公式需要调整：

| 击杀数区间 | 敌人组成比例 |
|---|---|
| 0~19 | 80% 近战 + 20% 哨兵 |
| 20~49 | 60% 近战 + 25% 哨兵 + 15% 渡鸦 |
| 50+（BOSS 战后重置） | 50% 近战 + 30% 哨兵 + 20% 渡鸦 |

### 生成算法调整

每次生成敌人时，根据当前击杀数决定敌人类型：
1. 随机选择敌人类型（根据上述比例）
2. 在屏幕外随机边缘生成该类型敌人
3. 生成间隔 spawn_interval 仍然受难度递增影响（下限 0.8 秒）

## 五、升级选项扩展

新增 2 个升级选项，丰富玩家应对新敌人的策略：

| 升级名称 | 效果 | 最大叠加 |
|---|---|---|
| 范围射击 | 导弹命中时对 80 像素内敌人造成 50% 溅射伤害 | 2 次 |
| 移动射击 | 移动时射速提升 15%（与站桩时叠加） | 2 次 |
