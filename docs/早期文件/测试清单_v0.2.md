# 测试清单 — v0.2

> 测试前准备：用 Godot 4.6.x 打开项目，按 F6 运行

---

## P0 — 核心功能（必须通过）

### P0.1 移动与转向
- [ ] WASD 四方向移动是否正常
- [ ] 移动时舰船朝向是否平滑跟随速度方向（无瞬移）
- [ ] 舰船是否被限制在屏幕边界内（move_and_slide）

### P0.2 自动索敌与射击
- [ ] 导弹是否按 fire_interval（默认 0.8s）自动发射（不按键）
- [ ] 导弹是否飞向最近敌人（within missile_range 默认 600px）
- [ ] 导弹命中敌人后是否消失
- [ ] 敌人被击杀后是否掉落经验球
- [ ] 无敌人时是否不发射导弹
- [ ] 导弹超出 3 秒后是否自动消失

### P0.3 伤害与护盾
- [ ] 敌人接触玩家是否扣血（基于 enemy_damage）
- [ ] 护盾是否优先于 HP 承受伤害
- [ ] 护盾是否每秒回充（默认 4/秒，上限 50）
- [ ] 暂停期间护盾是否停止回充
- [ ] 闪避（dodge）是否在伤害前触发
- [ ] 暴击（crit）是否在伤害计算中生效，显示 "!" 伤害数字
- [ ] HP 归零时是否弹出结算界面

### P0.4 经验与升级
- [ ] 拾取经验球后经验条是否增长
- [ ] 经验满时是否弹出三选一升级界面
- [ ] 选择升级后效果是否生效（Player 属性被刷新）
- [ ] 升级期间游戏是否冻结（get_tree().paused = true）
- [ ] 升级选择完成后游戏是否继续
- [ ] ESC/取消键是否可跳过本次升级（不选）
- [ ] 鼠标点击按钮是否可选择升级

### P0.5 难度递增
- [ ] 每击杀 20 只敌人后敌人生成间隔是否缩短（-0.1s，最低 0.8s）
- [ ] 每击杀 20 只敌人后敌人体质是否增强（hp *= 1.1）
- [ ] 后期敌人血量是否变高（能抗更多导弹）

## P2 — 升级效果验证

> 测试方法：反复升级同一选项直到最大次数，确认效果叠加

| 升级 | ID | 效果 | 最大次数 | 叠加后预期值 |
|------|----|------|----------|--------------|
| 射速提升 | `fire_rate` | fire_interval × 0.9 | 3 | 0.8 × 0.9³ ≈ 0.583s |
| 伤害强化 | `damage` | damage × 1.2 | 3 | 15 × 1.2³ ≈ 25.9 |
| 护盾上限 | `shield_max` | shield_max += 30 | 3 | 50 + 90 = 140，盾回满 |
| 移动加速 | `move_speed` | move_speed × 1.10 | 3 | 320 × 1.1³ ≈ 425 |
| 弹幕扩散 | `spread` | count+1，伤害×0.85 | 2 | 3发，每发85%伤害 |
| 生命回复 | `lifesteal` | HP += 2/s | 3 | 6 HP/s |
| 导弹强化 | `missile_count` | count+1 | 2 | 3发（无角度偏移） |
| 护盾充能 | `shield_regen` | regen × 1.5 | 2 | 4 × 1.5² = 9/s |
| 经验加成 | `xp_boost` | orb × 1.5 | 3 | orb × 3.375 |
| 闪避精通 | `dodge` | dodge += 0.05 | 3 | 0.1 + 0.15 = 0.25（25%） |

- [ ] 每项升级效果叠加验证

## 已知限制（v0.2 范围）

- 所有精灵为占位色块，无正式美术资源
- 无音效和粒子特效（部分粒子已实现）
- 无存档系统（GameState 仅运行时有效）
- 无闯关模式
- 敌人只有近战类型（EnemyMelee）
- 导弹无追踪能力，仅直线飞行
