## 一、种族选择界面

### 位置

主菜单点击"开始游戏"后，先进入种族选择界面，再进入游戏。

### 界面设计

- 背景：深空星图（与主菜单风格一致）
- 左侧：种族列表（竖排按钮）

| 种族 | 状态 |
|---|---|
| 人类 | 已解锁 |
| 兽人 | 已解锁 |
| 植物 | 敬请期待 |
| 硅基 | 敬请期待 |
| 神族 | DLC |

- 右侧：选中种族的详细信息面板
  - 种族名称
  - 种族简介（一句话描述）
  - 基础属性面板
  - 默认武器信息
  - 种族天赋描述

### 交互逻辑

1. 点击左侧种族按钮 → 右侧更新该种族信息
2. 点击"确认选择"按钮 → 进入游戏（加载对应种族属性）
3. 点击"返回"按钮 → 回到主菜单

## 二、兽人种族属性模板

### 兽人族简介

> 诞生于高重力星球的战斗种族，偏爱粗暴直接的火力。兽人的加农炮可以在极限射程内撕碎任何护盾，他们的造船哲学是"装甲够厚就不需要闪避"。

### 基础属性（对比人类）

| 属性 | 人类（现有） | 兽人（新增） | 说明 |
|---|---|---|---|
| HP | 100 | 120 | 兽人更耐打 |
| 护盾上限 | 50 | 30 | 兽人盾薄 |
| 护盾回充 | 4/秒 | 2/秒 | 兽人盾回得慢 |
| 移动速度 | 320 | 280 | 兽人稍慢 |
| 闪避率 | 10% | 5% | 兽人靠甲不靠闪 |
| 暴击率 | 5% | 3% | 兽人不靠暴击 |
| 默认武器 | 导弹 | 加农炮 | |

### 种族天赋

| 天赋名称 | 效果 |
|---|---|
| 重型装甲 | 受到的所有伤害 -10%（被动减伤） |
| 炮术专精 | 加农炮射速 +15% |

## 三、加农炮武器属性

| 属性 | 值 | 对比导弹 |
|---|---|---|
| 伤害 | 25 | 导弹 15 |
| 射击间隔 | 1.2 秒 | 导弹 0.8 秒 |
| 弹速 | 800 像素/秒 | 导弹 600 |
| 射程 | 400 像素 | 导弹 500 |
| 暴击倍率 | 1.2x | 导弹 1.5x |
| 弹道表现 | 直线穿透（可穿过第一个敌人继续飞行） | 导弹命中即消失 |

## 四、需要新增/修改的文件

### 新增文件

| 文件路径 | 说明 |
|---|---|
| scenes/RaceSelect.tscn | 种族选择界面场景 |
| scripts/race_select.gd | 种族选择界面脚本 |
| resources/race_data.gd | 种族数据资源（定义各种族属性模板） |
| scenes/CannonBullet.tscn | 加农炮弹丸场景 |
| scripts/cannon_bullet.gd | 加农炮弹丸脚本 |

### 需要修改的文件

| 文件路径 | 修改内容 |
|---|---|
| scenes/MainMenu.tscn | "开始游戏"按钮改为跳转到种族选择界面 |
| scripts/game_manager.gd | 初始化时读取所选种族数据应用到玩家 |
| scripts/player.gd | 支持根据种族数据设置初始属性 |
| scripts/upgrade_menu.gd | 如果种族有专属升级选项，加入条件判断 |
