## 一、武器子弹效果美化

### 1.1 当前实现分析

四种武器目前全部使用 **纯代码程序化绘制**（Polygon2D + _draw trail），功能完整但视觉效果朴素：

| 武器 | 子弹形态 | 拖尾效果 | 命中效果 |
|------|----------|----------|----------|
| 加农炮 | 橙色菱形（Polygon2D） | 橙色渐隐线条（_draw） | 无 |
| 导弹 | 黄色菱形（Polygon2D） | 橙色渐隐线条（_draw） | CPUParticles2D 爆炸 |
| 磁轨炮 | 青绿色菱形（Polygon2D） | 青绿色渐隐线条（_draw） | 无 |
| 激光炮 | 双层 Line2D 光束 | 静态双线（核心+光晕） | 无 |

**现有脚本：** `scripts/cannon_bullet.gd`、`scripts/missile.gd`、`scripts/railgun_bullet.gd`、`scripts/laser_beam.gd`

## 三、战斗场景背景美术素材

### 3.1 当前实现分析

场景文件：`scenes/GameScene.tscn`
脚本：`scripts/game_scene.gd` + `scripts/parallax_starfield.gd`

**当前结构：**
```
GameScene (Node2D)
├── BackgroundLayer (CanvasLayer, layer=-100)
│   └── Background (ColorRect) — 纯黑 #000005
├── GameManager
├── PlayerRoot
├── EnemyRoot
├── BulletRoot
├── ExpOrbRoot
├── DamageRoot
├── ParallaxStarfield (跟随相机，三层视差星星+闪烁)
└── UIRoot
```

**当前视觉：**
- 背景层：纯黑 `Color(0.0, 0.0, 0.02)` 填满屏幕
- 星空：三层程序化绘制（draw_circle）的星星，带视差滚动和闪烁动画
- 三层参数：
  - 远景层（0.15x 视差）：1300颗，暖白 `Color(1.0, 0.95, 0.85)`，小尺寸
  - 中景层（0.35x 视差）：900颗，冷蓝白 `Color(0.85, 0.9, 1.0)`
  - 近景层（0.60x 视差）：550颗，亮蓝白 `Color(0.7, 0.8, 1.0)`
- 无任何图片资产

**注意：** `shaders/ship_tint.gdshader` 和 `shaders/wreck_effect.gdshader` 是舰船/残骸效果着色器，非背景着色器。
