## 一、基地场景

### 场景设计

- 背景：空间站内部（深色金属风格）
- 视角：2D 俯视或静态界面（MVP 建议用静态界面，类似菜单但更有氛围）
- 功能区域（用按钮或可点击区域表示）：
  - 维修站
  - 合成台
  - 舰船仓库
  - 出发战斗
  - 返回主菜单

### 交互流程

```
主菜单 → 种族选择 → 进入基地 → 选择功能 → 出发战斗
                                   ↑
                           战斗结束返回基地
```

## 三、装备合成系统

### 合成规则

合成路径：

```
普通（Common）→ 精良（Uncommon）→ 稀有（Rare）→ 传奇（Legendary）→ 传说（Epic）→ 神话（Mythic）
```

合成公式：
- 2 件同品质装备 = 1 件下一品质装备
- 消耗一定数量的星币作为合成费用
- 合成结果随机选择同类装备（武器合武器，防具合防具）

### 合成费用表

| 合成目标品质 | 星币费用 |
|---|---|
| 普通 → 精良 | 200 |
| 精良 → 稀有 | 500 |
| 稀有 → 传奇 | 1,500 |
| 传奇 → 传说 | 5,000 |
| 传说 → 神话 | 20,000 |

### 装备属性提升

| 品质 | 属性加成倍率 | 说明 |
|---|---|---|
| 普通 | 1.0x | 基础值 |
| 精良 | 1.2x | 比普通强 20% |
| 稀有 | 1.5x | 比普通强 50% |
| 传奇 | 2.0x | 比普通强一倍 |
| 传说 | 2.8x | |
| 神话 | 4.0x | |

### 装备掉落规则

- 战斗中敌人有概率掉落装备（MVP 阶段：每个敌人 10% 概率掉落一件随机品质装备）
- BOSS 必定掉落一件稀有或以上品质装备
- 掉落的装备自动存入仓库

## 四、舰船仓库

### 功能

- 显示已解锁的舰船列表
- 每艘船显示：名称、状态（完好/损坏）、当前装备槽位
- 选中舰船可以查看详细属性
- 点击"装备"按钮进入装备配置界面

### 装备配置界面

- 显示当前舰船的武器槽和防槽
- 每个槽位显示当前装备的名称和品质
- 点击槽位弹出可用装备列表
- 选择装备进行更换
