## 四、建筑详情面板不透明背景

### 设计动机

点击建筑后弹出的功能面板原本背景透明，与基地背景混在一起，文字可读性差。改为不透明背景后视觉层次更清晰。

### 技术实现

在 `base_scene.gd` 中新增两个函数：

- `_switch_panel()`：打开面板时调用 `_set_panel_opaque(panel, true)` 设置不透明样式
- `_set_panel_opaque(panel, opaque)`：为面板根节点下的 `Panel` 节点动态应用 `StyleBoxFlat` 样式

```gdscript
func _set_panel_opaque(panel: Control, opaque: bool) -> void:
    var p: Panel = panel.find_child("Panel", false, false) as Panel
    if p:
        var style := StyleBoxFlat.new()
        style.bg_color = Color(0.05, 0.05, 0.1, 0.97) if opaque else Color(0, 0, 0, 0)
        style.set_border_width_all(2)
        style.border_color = Color(0.2, 0.3, 0.5, 1.0)
        style.set_corner_radius_all(8)
        p.add_theme_stylebox_override("panel", style)
```

### 涉及面板（7 个）

维修站、装备合成、武器商店、物品仓库、造船厂、科研中心、星港

### Bug 修复

- **Godot 4 API 兼容性**：Godot 4 的 `StyleBoxFlat` 不存在 `set_border_color_all()` 方法，改用 `border_color` 属性（会自动应用到所有边）
