## 二、Bug 修复

### 2.1 导弹扇形发射角度修正

修正了「火力覆盖」升级的扇形角度，Lv.3 不再是 -4°/+4°/-12°/+12°，改为严格等间隔 8 度：

| 等级 | 子弹数 | 角度 |
|------|--------|------|
| Lv.0 | 1枚 | 0° |
| Lv.1 | 2枚 | -8° / +8° |
| Lv.2 | 3枚 | -8° / 0° / +8° |
| Lv.3 | 4枚 | -12° / -4° / +4° / +12° |

### 2.2 人类种族天赋生效

人类「导弹基础等级 +1」天赋现已生效，开局自动获得以下三项 Lv.1（不占用局内升级次数）：

| 升级项 | 开局等级 | 局内可再升 | 最高 |
|--------|---------|-----------|------|
| 火力覆盖 | Lv.1（天赋） | +2次 | Lv.3 |
| 静默猎手 | Lv.1（天赋） | +2次 | Lv.3 |
| 精准猎杀 | Lv.1（天赋） | +2次 | Lv.3 |

> 注：局内升级三选一时，若该升级已达局内+3上限则不会出现在选项中。

### 2.3 护卫舰槽位

确认护卫舰升级前 **1武1防**，升级后 **2武1防**，符合设计预期。

## 三、升级系统精简

### 3.1 删除的升级项

共删除 6 项冗余 / 重复升级：

| 武器 | 删除项 | 原效果 |
|------|--------|--------|
| 导弹 | 导弹速射 | 导弹射速 +20% |
| 导弹 | 弹头强化 | 导弹伤害 +25% |
| 导弹 | 制导增强 | 导弹索敌范围 +100 |
| 加农炮 | 穿透强化 | 穿透 +1 个目标 |
| 加农炮 | 炮管冷却 | 加农炮射速 +20% |
| 加农炮 | 高爆弹药 | 30% 概率爆炸（80px） |

精简后各武器专属升级均为 3 项：

| 武器 | 专属升级 |
|------|---------|
| 导弹 | 火力覆盖、静默猎手、精准猎杀 |
| 加农炮 | 嗜血残暴、狂飙突进、为了部落 |
| 磁轨炮 | 一发入魂、命中注定、多重射击 |
| 激光炮 | 高能光束、高效射击、护盾中和 |

通用升级（3项）：伤害强化、临时护盾、护盾充能

### 3.2 权重调整

| 升级项 | 旧权重 | 新权重 |
|--------|--------|--------|
| 一发入魂 | mid（中等） | **low（低）** |
| 静默猎手 | 3.0 | **2.0** |
| 精准猎杀 | 3.0 | **2.0** |
| 嗜血残暴 | 6.0 | **4.0** |
| 高能光束 | 6.0 | **4.0** |

### 3.3 6 级上限说明

每个升级项的最大等级由三部分组成：

| 等级来源 | 数值 |
|----------|------|
| 种族天赋 | +1（开局自带） |
| 局内三选一 | 最多 +3 |
| 科研建筑 | 最多 +2（后续版本预留） |

局内三选一时，升级池会自动过滤掉已达局内+3上限的升级项。

## 五、物品仓库改造

### 5.1 界面改造

仓库界面重新布局为分栏设计：

- **上方**：当前舰船信息（舰船名、武器槽数量、防御槽数量）
- **左侧**：已装备栏 — 显示当前舰船已安装的武器和防御
- **右侧**：库存栏 — 仓库中所有未装备的装备

### 5.2 装备 / 卸下功能

| 操作 | 说明 |
|------|------|
| 点击已装备项 | 显示详情，启用「卸下」按钮 |
| 点击库存项 | 显示详情，启用「装备」按钮 |
| 卸下 | 装备返回仓库，对应槽位变空 |
| 装备 | 装备到舰船对应槽位；若槽位已满则提示 |
| 空配置 | 支持卸下所有装备，槽位留空 |

## 六、基地 ESC 菜单

基地界面新增 ESC 菜单，取代原来的右下角「返回主菜单」按钮：

| 按钮 | 功能 |
|------|------|
| 返回游戏 | 关闭菜单，继续基地操作 |
| 返回主菜单 | 回到主菜单界面 |
| 结束游戏 | 退出游戏 |

> 注：ESC 菜单弹出时游戏暂停（`get_tree().paused = true`）。

## 八、磁轨炮多重射击改为连续发射

「多重射击」升级效果由原来的单次同时发射多枚，改为**极短时间内的连续发射**：

| 等级 | 效果 |
|------|------|
| Lv.0 | 单次发射 1 枚 |
| Lv.1 | 连续发射 2 次，间隔 0.1 秒 |
| Lv.2 | 连续发射 3 次，间隔 0.1 秒 |
| Lv.3 | 连续发射 4 次，间隔 0.1 秒 |
