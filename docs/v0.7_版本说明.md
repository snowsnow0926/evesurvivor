## 二、游戏流程重做

### 首次进入游戏（first_run = true）
- 显示 5 分钟倒计时（300秒）
- 倒计时结束后强制返回基地（100% 收益）
- 结算界面显示：击杀数 + 获得星币

### 第二次及之后进入游戏
- **无倒计时**
- 游戏进行到舰船死亡为止
- 阵亡结算：50% 星币 + 50% 矿物，舰船损坏

### ESC 暂停菜单
- 继续 / 撤离并结算（返回基地，100% 收益）/ **新增：自毁**
- 自毁：直接返回基地，无收益，舰船状态不变
