## 二、音效系统

### 音效触发点

|| 音效 | 触发时机 |
|------|------|
| `shoot_missile` | 导弹发射 |
| `shoot_cannon` | 加农炮发射 |
| `shoot_railgun` | 磁轨炮发射 |
| `shoot_laser` | 激光炮发射 |
| `hit` | 子弹命中敌人 |
| `crit` | 暴击触发 |
| `shield_hit` | 护盾受到伤害（非致命） |
| `shield_break` | 护盾归零 |
| `player_hurt` | HP 受到伤害 |
| `enemy_death` | 敌人死亡 |
| `upgrade` | 升级界面弹出 |
| `upgrade_select` | 选择升级选项 |
| `player_death` | 玩家阵亡 |
| `boss_appear` | BOSS 出场 |
| `boss_death` | BOSS 被击杀 |
| `button_click` | 按钮点击（继续、返回基地等） |
| `retreat_success` | 撤离成功 |

### 实现方式

- `SoundManager` Autoload 节点统一管理
- 每种音效对应一个 `AudioStreamPlayer`，支持同时播放多个同类型音效
- 背景音乐使用独立 `AudioStreamPlayer`，支持淡入淡出切换

### 资源接入方式

音效资源路径在 `SoundManager.SFX_RESOURCES` 字典中配置：

```gdscript
const SFX_RESOURCES: Dictionary = {
    "shoot_missile": "res://assets/sfx/shoot_missile.ogg",
    # ... 其他音效
}
```

将对应 `.ogg` 文件放入 `assets/sfx/` 目录，并将路径填入即可启用。

## 四、新手引导

### 触发条件

- `GameState.first_run == true`（首次进入游戏）
- 首次运行结束后 `first_run` 标记为 `false`，不再触发

### 引导步骤

|| 步骤 | 内容 |
|------|------|------|
| 1 | WASD 移动你的舰船 | 屏幕中央下方 |
| 2 | 敌人会自动出现，武器会自动射击 | 屏幕上方 |
| 3 | 靠近蓝色发光球体获取经验值 | 屏幕左侧 |
| 4 | 经验条满了之后选择升级来强化你的舰船 | 屏幕中央 |
| 5 | 按 ESC 暂停，可以选择撤离结算 | 屏幕右上角 |
| 6 | 活下去，攒钱，换更大的船！ | 屏幕中央 |

### 引导样式

- 半透明黑色遮罩（60% 透明度）
- 提示文字：白色，24px，带发光描边
- 闪烁箭头指向关键 UI 元素
- 点击任意位置或按空格/回车进入下一步
- 按 ESC 跳过引导

### 实现细节

- `NewbieGuide` 以 `CanvasLayer` 形式动态挂载到 `GameScene`，层序 200
- 与游戏信号链松耦合，通过 `guide_completed` 信号通知 `GameScene`
- 升级弹出时通知引导（步骤 4），ESC 暂停时通知引导（步骤 5）

## 五、数值平衡配置文件

### 文件路径

`resources/game_balance.json`

### 配置内容

| 区块 | 内容 |
|------|------|
| `player` | 玩家基础属性（移速/HP/护盾/暴击等） |
| `weapons` | 四种武器基础参数（射速/伤害/射程等） |
| `enemies` | 四类敌人参数（HP/伤害/移速/技能参数） |
| `spawn` | 敌人生成间隔和距离 |
| `rewards` | 击杀奖励（星币/矿物，按敌人类型） |
| `combo` | 连击超时和倍率上限 |
| `xp` | 经验系统参数 |
| `upgrades` | 所有升级项的倍率/加成参数 |
| `difficulty` | 难度递增参数 |
| `settlement` | 结算收益比例 |

### 使用方式

```gdscript
# 读取示例
var speed = GameBalance.get_player("move_speed", 320)
var missile_damage = GameBalance.get_weapon("missile", "damage", 15)
var melee_reward = GameBalance.get_reward("melee")
var pierce_add = GameBalance.get_upgrade("cannon_pierce").get("add", 1)
```

数值文件加载为 `GameBalance` Autoload 节点，可随时热更新 JSON 后重新加载，无需改代码。
