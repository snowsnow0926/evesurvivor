## 一、加农炮武器（完整版）

### 属性

| 属性 | 值 |
|---|---|
| 伤害 | 25 |
| 射击间隔 | 1.2 秒 |
| 弹速 | 800 像素/秒 |
| 射程 | 400 像素 |
| 暴击倍率 | 1.2x |

### 弹道特性

- 直线穿透：加农炮弹丸穿过第一个敌人后继续飞行
- 穿透后伤害衰减 20%（第二目标受到 20 伤害，第三目标 16，依此类推）
- 最多穿透 3 个敌人

### 外观建议

- 较大的弹丸（比导弹大一倍）
- 颜色：橙黄色（与导弹的蓝色区分）

## 二、局内武器切换系统

### 触发方式

- 升级时增加"获得新武器"选项
- 如果玩家已经拥有两种武器，则显示"切换武器"选项

### 双武器规则

- 玩家同时只能携带 2 种武器
- 两种武器**同时自动索敌射击**，各自独立计算冷却
- 两种武器共享同一个索敌范围（取较大值）

### 切换交互

- 按 Q 键切换当前主武器
- 主武器在 HUD 上高亮显示
- 升级时优先应用于主武器

## 三、武器专属升级选项

### 导弹专属升级

| 升级名称 | 效果 | 最大叠加 |
|---|---|---|
| 导弹速射 | 导弹射速 +20% | 3 |
| 制导增强 | 导弹索敌范围 +100 像素 | 2 |
| 弹头强化 | 导弹伤害 +25% | 3 |

### 加农炮专属升级

| 升级名称 | 效果 | 最大叠加 |
|---|---|---|
| 穿透强化 | 加农炮穿透 +1 个目标 | 2 |
| 炮管冷却 | 加农炮射速 +20% | 3 |
| 高爆弹药 | 加农炮命中时 30% 概率爆炸（80 像素范围，50% 伤害） | 2 |

### 通用升级（已有）

射速提升、伤害强化、移动加速、护盾上限、生命回复、弹幕扩散（仅导弹）
