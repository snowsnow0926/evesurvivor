## icon_definitions.json 字段说明

```json
{
  "ships": [
    {
      "id": "battleship",
      "name_zh": "战列舰",
      "name_en": "Battleship",
      "path": [["M", 50, 20], ["L", 80, 50], ["L", 50, 80], ["L", 20, 50], ["Z"]]
    }
  ]
}
```

### 字段含义

| 字段 | 类型 | 说明 |
|---|---|---|
| `id` | String | 图标唯一标识，需与文件名（去掉 `_32.png` 后缀）对应 |
| `name_zh` | String | 中文显示名称 |
| `name_en` | String | 英文名称 |
| `path` | Array | SVG 路径数据，格式为 `[[命令, 参数...], ...]` |

### path 命令格式

| 命令 | 说明 | 参数 |
|---|---|---|
| `M` | 移动到（起始点） | `x, y` |
| `L` | 直线到 | `x, y` |
| `Q` | 二次贝塞尔曲线 | `cx, cy, ex, ey` |
| `Z` | 闭合路径 | 无 |

## 导入流程

1. 将 PNG 文件放入 `res://resources/icons/` 目录
2. 在 Godot 中打开 `ShipIconEditor` 场景进行绘制
3. 保存后自动写入 `res://resources/icon_definitions.json`
4. `ShipIconGenerator` 自动加载并在需要时生成 `Texture2D`
