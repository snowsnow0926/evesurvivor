## 二、背景音乐

### 音乐轨

| 场景 | 音乐风格建议 |

| 主菜单 | 低沉、空旷的太空氛围 |
| 种族选择 | 同上或者轻柔过渡 |
| 基地 | 稳定、中性的背景 |
| 战斗（普通） | 中等节奏，保持紧张感但不强烈 |

### 实现方式

- 使用 AudioStreamPlayer（不要用 2D 版，全局播放）
- 场景切换时平滑过渡（淡入淡出）

## 三、新手引导

### 触发条件

- 首次进入游戏（通过 GameState 记录是否首次）
- 首次进入时，覆盖一层半透明遮罩 + 指引提示

### 引导步骤

| 步骤 | 提示内容 | 位置 |
|---|---|---|
| 1 | WASD 移动你的舰船 | 屏幕中央下方 |
| 2 | 敌人会自动出现，导弹会自动射击 | 屏幕上方 |
| 3 | 靠近经验球（蓝色发光球体）获取经验 | 指向第一个经验球 |
| 4 | 经验满后选择升级强化你的舰船 | 升级界面出现时 |
| 5 | 按 ESC 暂停并可以随时撤离结算 | 屏幕右上角 |
| 6 | 活下去，攒钱，换更大的船 | 结算界面 |

### 引导样式

- 半透明黑色遮罩（60% 透明度）
- 提示文字：白色，带发光边框，字号 24
- 指向性箭头：闪烁动画指向关键 UI 元素
- 玩家点击任意处或完成当前步骤后进入下一步

## 四、数值平衡调整

### 需要实机测试并调整的数值

**玩家侧**

| 数值 | 当前值 | 调整方向（需测试确认） |
|---|---|---|
| 护卫舰 HP | 100 | 如果前期太容易死 → 提升至 120 |
| 护卫舰移速 | 320 | 如果躲不开弹幕 → 提升至 350 |
| 导弹伤害 | 15 | 如果清怪太慢 → 提升至 18 |
| 导弹射速 | 0.8 秒 | 如果太慢 → 提升至 0.7 秒 |

**敌人侧**

| 数值 | 当前值 | 调整方向 |
|---|---|---|
| 近战敌人 HP | 30 | 如果前期太难 → 降低至 25 |
| 近战敌人伤害 | 10 | 如果被摸几下就死 → 降低至 8 |
| 生成间隔初始值 | 2.0 秒 | 如果前期太闲 → 降至 1.8 秒 |
| 生成间隔下限 | 0.8 秒 | 如果后期太密集 → 下限改为 1.0 秒 |
| 远程敌人 HP | 20 | 如果太脆 → 提升至 25 |
| 自爆敌人伤害 | 25 | 如果炸一下太痛 → 降低至 20 |

**经济侧**

| 数值 | 当前值 | 调整方向 |
|---|---|---|
| 击杀星币 | +10 | 如果攒钱太慢 → 提升至 +15 |
| 击杀矿物 | +2 | 如果攒矿物太慢 → 提升至 +3 |
| 护卫舰维修费 | 500 | 如果太贵 → 降低至 300 |
| BOSS 星币奖励 | 100 | 如果太少 → 提升至 150 |

**升级侧**

| 升级 | 当前效果 | 调整方向 |
|---|---|---|
| 射速提升 | *0.9/次 | 如果太强 → 改为 *0.92/次 |
| 伤害强化 | *1.2/次 | 如果太强 → 改为 *1.15/次 |
| 护盾上限 | +30/次 | 如果太少 → 改为 +40/次 |
| 移动加速 | *1.10/次 | 如果走位太强 → 改为 *1.08/次 |

### 调整方法

1. 将以上数值提取到独立的数值配置文件中（JSON 或 Godot Resource）
2. 运行时读取配置文件，方便快速调整
3. 每次调整后记录调整内容 + 测试结果
