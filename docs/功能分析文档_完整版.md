## 1. 游戏概览与流程

### 1.1 游戏类型

太空射击类幸存者游戏（类似《吸血鬼幸存者》），玩家操控一艘舰船在无限刷敌的太空战场上生存，通过升级强化自身、解锁更强舰船、获取装备，最终挑战 Boss。

### 1.2 完整游戏流程

```
主菜单
  ├── 读取存档 → 基地场景
  ├── 新建游戏 → 角色创建 → 基地场景
  └── 退出游戏

基地场景（自由活动）
  ├── 商店 → 购买武器/防具
  ├── 仓库 → 管理装备（穿戴/卸下/出售）
  ├── 船坞 → 解锁/升级舰船
  ├── 维修站 → 修复损坏舰船
  ├── 合成台 → 装备品质升级
  ├── 科研中心 → 武器科技升级
  ├── 储物 → 舰船储物（下版本）
  └── 出战 → 章节选择 → 关卡选择 → 进入战斗

战斗场景（局内）
  ├── 战斗（击杀敌人获取经验和战利品）
  ├── 升级（选择强化项）
  ├── 暂停（撤离结算）
  └── 结束（死亡/时间到/撤离）→ 结算画面

结算画面
  ├── 查看战利品清单
  ├── 查看统计数据
  └── 返回基地 / 重新开始 / 返回主菜单
```

### 1.3 核心货币

| 货币类型 | 用途 |
|---------|------|
| 星币 | 购买装备、解锁舰船、维修、合成 |
| 低级矿物 | 前期消耗 |
| 中级矿物 | 中期消耗 |
| 高级矿物 | 后期消耗 |

## 2. 主菜单

### 2.1 功能列表

| 功能 | 说明 |
|------|------|
| 开始游戏 | 新建存档，进入角色创建流程 |
| 读取游戏 | 打开存档选择界面，选择已保存的存档位 |
| 退出游戏 | 退出程序 |

### 2.2 详细说明

**开始游戏**：点击后弹出存档选择界面，用户可以选择存档位（3个槽位），然后进入角色创建。如果选择的槽位已有存档，会询问是否覆盖。

**读取游戏**：列出所有存档位，显示每个存档的角色名、星币数量、最高等级、保存时间。点击"读取"加载存档并进入基地场景。

**退出游戏**：点击后直接关闭游戏窗口。

## 3. 存档系统

### 3.1 功能列表

| 功能 | 说明 |
|------|------|
| 多槽位存档 | 支持 3 个独立存档位 |
| 自动存档 | 购买装备后自动保存 |
| 存档信息 | 显示角色名、星币、等级、保存时间 |
| 存档覆盖 | 选择已有存档会提示是否覆盖 |
| 新游戏 | 清除当前存档数据，重新创建角色 |

### 3.2 详细说明

每个存档位保存以下数据：
- **玩家信息**：角色名、种族、当前舰船
- **货币**：星币、低级/中级/高级矿物数量
- **装备**：背包中的装备列表、当前舰船的武器和防具装备
- **舰船**：已解锁舰船列表、已升级舰船列表
- **进度**：章节/关卡解锁状态、研究进度
- **局内记录**：上次战斗结果（失败/完成/撤离）、舰船损坏状态
- **元数据**：保存时间戳

### 4.2 种族详情

| 种族 | 默认武器 | HP | 护盾 | 护盾回复 | 移速 | 闪避 | 暴击率 | 暴击倍率 | 天赋 1 | 天赋 2 |
|------|---------|-----|------|---------|------|------|--------|---------|--------|--------|

| **兽族** | 加农炮 | 120 | 30 | 2/s | 280 | 5% | 3% | 1.2x | 炮术专精（加农炮基础等级+1）| 狂暴射击（加农炮射速+15%）|

- 兽族：高 HP 低护盾，加农炮近身战斗
- 植物：高暴击，磁轨炮高伤害精准打击
- 硅基：高护盾，激光炮持续输出

**初始资金**：新角色创建时获得 10,000,000 星币、200,000 低级矿物、200,000 中级矿物、200,000 高级矿物（开局大量资源）。

## 5. 基地场景

### 5.1 功能列表

| 功能 | 说明 |
|------|------|
| 功能面板切换 | 显示/隐藏 7 种基地设施面板 |
| 货币实时显示 | 顶部显示当前星币和矿物数量 |
| 出战检查 | 无武器时禁止进入战斗，弹出警告 |
| 暂停菜单 | 按 ESC 打开基地暂停菜单 |
| 音乐播放 | 播放基地专属背景音乐 |

### 5.2 详细说明

基地是战斗之间的中转站。玩家可以在此管理装备、舰船和科研，然后选择进入战斗。基地场景顶部显示当前货币余额，玩家点击左侧导航按钮切换不同功能面板。**如果没有装备任何武器，点击出战会弹出警告提示，3 秒后自动消失**。

基地暂停菜单可执行：继续（关闭菜单）、保存游戏、读取游戏、返回主菜单、退出游戏。

|------|------|
| 商品购买 | 花费星币购买武器或防具 |
| 装备出售 | 将仓库中的装备按原价 40% 出售 |

## 7. 基地设施 — 仓库

### 7.1 功能列表

| 功能 | 说明 |
|------|------|
| 装备穿戴 | 从仓库取出装备到当前舰船的空槽 |
| 装备卸下 | 将舰船上的装备卸下放回仓库 |
| 装备出售 | 按原价 40% 出售仓库中的装备 |
| 装备详情 | 显示名称、品质、完整属性（武器：DPS/伤害/射速/射程/暴击；防具：护盾加成/回复加成）|
| 品质颜色 | 装备按品质显示不同颜色（普通→精良→稀有→传奇→史诗→神话）|
| 吨位提示 | 显示装备是否与当前舰船吨位匹配 |
| 装备对比 | 仓库中已装备的装备以特殊标记区分 |

### 7.2 详细说明

仓库界面分为三个区域：
- **武器槽**：显示当前舰船的武器槽数量和已装备武器，空槽显示"空武器槽"
- **防具槽**：显示当前舰船的防具槽数量和已装备防具，空槽显示"空防御槽"
- **仓库库存**：显示所有未装备的物品列表

仓库中已装备的物品以 `[装]` 前缀标记，仓库中的物品以 `[仓]` 前缀标记。品质越高颜色越鲜艳：白色→绿色→蓝色→紫色→橙色→深红色。

## 10. 基地设施 — 合成台

### 10.1 功能列表

| 功能 | 说明 |
|------|------|
| 手动合成 | 选择 2 件同品质装备，消耗星币合成为下一品质 |
| 一键合成 | 自动寻找所有可合成的配对，批量执行合成 |
| 合成预览 | 显示合成结果品质、名称和消耗金额 |
| 品质限制 | 最高可合成到"神话"品质（无法继续合成）|
| 类型保护 | 只允许武器与武器合成、防具与防具合成 |
| 名称净化 | 合成时自动剥离品质前缀避免叠加 |

### 10.2 合成链与费用

```
普通(1.0x) → 精良(1.3x) → 稀有(1.6x) → 传奇(2.0x) → 史诗(2.8x) → 神话(4.0x)

普通→精良: 200星币
精良→稀有: 500星币
稀有→传奇: 1,500星币
传奇→史诗: 5,000星币
史诗→神话: 20,000星币
```

### 10.3 详细说明

合成需要两件**相同品质**的装备，产物为下一品质。例如两件"精良护卫舰加农炮"合成一件"稀有护卫舰加农炮"。属性按品质倍率提升（精良伤害×1.3，稀有×1.6）。合成名称自动剥离旧品质前缀（如"精良护卫舰加农炮"变成"护卫舰加农炮"，再缀上新品质前缀）。一键合成会从低品质到高品质依次处理仓库中的所有可合成配对，直到没有足够的配对或星币不足。

## 11. 基地设施 — 科研中心

### 11.1 功能列表

| 功能 | 说明 |
|------|------|
| 武器科技列表 | 显示全部 12 种武器科技的研究状态 |

### 11.2 科技清单

**导弹科技（3 种，每种 2 级）**：

| 科技ID | 名称 | 效果 | 费用（Lv.1）| 费用（Lv.2）|
|--------|------|------|------------|------------|

### 17.2 锁定时序

```
发现敌人
  → [锁定中] 黄色角框出现，敌人无敌静止，持续 1.0 秒
  → [闪烁] 黄色角框明暗闪烁 3 次（每次 0.25 秒），共 0.75 秒
```

## 24. 局内 UI — 暂停菜单

### 24.1 功能列表

| 功能 | 说明 |
|------|------|
| 暂停游戏 | 按 ESC 暂停游戏，弹出暂停菜单 |
| 继续游戏 | 关闭菜单继续战斗 |
| 撤离结算 | 放弃当前战斗，保留 100% 收益返回基地 |

## 27. 新手引导

### 27.1 功能列表

| 功能 | 说明 |
|------|------|
| 首次引导 | 首次进入游戏时显示 6 步引导教程 |
| 步骤说明 | 逐条显示游戏基本操作提示 |
| 跳过功能 | 按 ESC 或点击跳过引导 |
| 步进触发 | 点击屏幕或按空格/回车进入下一步 |
| 暂停联动 | 引导第 5 步（暂停说明）会在打开暂停菜单时自动推进 |
| 引导完成 | 完成后记录状态，后续不再显示 |

### 27.2 引导步骤

1. WASD 移动你的舰船
2. 敌人会自动出现，武器会自动射击
3. 靠近蓝色发光球体获取经验值
4. 经验条满了之后选择升级来强化你的舰船
5. 按 ESC 暂停，可以选择撤离结算
6. 活下去，攒钱，换更大的船！

### 27.3 详细说明

引导在半透明黑色遮罩上显示步骤文字，带有箭头指向提示。引导仅在 `GameState.first_run == true` 时自动启动，引导完成后标记为已完成。引导期间玩家可以随时点击或按键跳过。
