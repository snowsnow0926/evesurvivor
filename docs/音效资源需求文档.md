# 音效资源需求文档

> 创建时间：2026-04-30
> 用途：为 `scripts/sound_manager.gd` 提供音效和音乐文件

---

## 目录结构

```
assets/
├── sfx/          # 音效文件（短促，触发时播放）
└── music/       # 音乐文件（循环播放）
```

## 一、音效文件（sfx/）

### 文件清单

| 文件名 | 时长建议 | 说明 | 触发时机 |
|--------|---------|------|----------|
| `shoot_missile.ogg` | 0.1-0.2s | 导弹发射，短促推进器声 | 导弹武器开火 |
| `shoot_cannon.ogg` | 0.1-0.2s | 加农炮开火，炮击感 | 加农炮武器开火 |
| `shoot_railgun.ogg` | 0.1-0.3s | 磁轨炮充能发射，高频嗡鸣 | 磁轨炮武器开火 |
| `shoot_laser.ogg` | 0.1-0.2s | 激光束发射，滋滋声 | 激光炮开火 |
| `hit.ogg` | 0.05-0.15s | 子弹命中，清脆打击感 | 敌人受击（非暴击） |
| `crit.ogg` | 0.1-0.2s | 暴击命中，比普通命中更响亮 | 触发暴击时 |
| `shield_hit.ogg` | 0.1-0.2s | 护盾受击，低频沉闷 | 护盾扣血（非归零） |
| `shield_break.ogg` | 0.2-0.4s | 护盾破碎，玻璃碎裂感 | 护盾归零瞬间 |
| `player_hurt.ogg` | 0.2-0.4s | 玩家受伤，比护盾受击更重 | HP 扣血 |
| `enemy_death.ogg` | 0.15-0.3s | 敌人死亡，短促消灭声 | 普通敌人死亡 |
| `upgrade.ogg` | 0.3-0.5s | 升级界面弹出，上升音调，正面反馈 | 触发升级时 |
| `upgrade_select.ogg` | 0.1-0.2s | 选择升级确认，叮一声 | 玩家选择升级选项 |
| `player_death.ogg` | 0.5-1.0s | 玩家阵亡，低沉失败音 | 玩家 HP 归零 |
| `boss_appear.ogg` | 0.5-1.0s | BOSS 出场，厚重、有压迫感 | BOSS 出场 |
| `boss_death.ogg` | 0.5-1.0s | BOSS 击杀，庆祝感，宏大 | BOSS 死亡 |
| `button_click.ogg` | 0.05-0.1s | 按钮点击，简单短促 | 所有 UI 按钮 |
| `retreat_success.ogg` | 0.3-0.6s | 撤离成功，安全着陆感 | 撤离结算成功 |

### 格式要求

- **格式**：`.ogg`（推荐）或 `.wav`
- **采样率**：44100 Hz
- **声道**：单声道（Mono）或立体声（Stereo）均可
- **位数深**：16-bit
- **时长**：尽量短（多数 < 0.5s），方便同时播放多个实例

### 音量参考

- 射击/命中等高频音效：建议 -3dB 到 0dB
- 爆炸/破碎等厚重音效：建议 -6dB 到 -3dB
- 背景触发音效（升级弹出）：建议 -6dB 到 -3dB
- 按钮点击：建议 -9dB 到 -6dB（不抢戏）

## 二、音乐文件（music/）

### 文件清单

| 文件名 | 时长建议 | 说明 | 触发场景 |
|--------|---------|------|----------|
| `menu.ogg` | 60-120s，循环 | 低沉、空旷的太空氛围 | 主菜单 |
| `race_select.ogg` | 30-60s，循环 | 轻柔过渡，空灵氛围 | 种族选择 |
| `base.ogg` | 60-120s，循环 | 稳定、中性的背景 | 基地 |
| `battle.ogg` | 60-120s，循环 | 中等节奏，保持紧张感但不强烈 | 战斗（普通） |
| `battle_boss.ogg` | 60-120s，循环 | 强烈节奏，提升紧迫感，压迫感 | 战斗（BOSS） |
| `settlement.ogg` | 30-60s | 平静收尾，舒缓 | 结算界面 |

### 格式要求

- **格式**：`.ogg`（推荐）或 `.wav`
- **采样率**：44100 Hz
- **声道**：立体声（Stereo）
- **位数深**：16-bit
- **循环**：音乐文件本身需要预留循环衔接点（开头和结尾淡出淡入约 0.5s）

### 音量参考

- 背景音乐整体：建议 -12dB 到 -9dB（不盖过音效）

## 三、接入方法

### 音效文件接入

编辑 `scripts/sound_manager.gd`，在 `SFX_RESOURCES` 字典中填入文件路径：

```gdscript
const SFX_RESOURCES: Dictionary = {
    "shoot_missile":   "res://assets/sfx/shoot_missile.ogg",
    "shoot_cannon":    "res://assets/sfx/shoot_cannon.ogg",
    "shoot_railgun":   "res://assets/sfx/shoot_railgun.ogg",
    "shoot_laser":     "res://assets/sfx/shoot_laser.ogg",
    "hit":             "res://assets/sfx/hit.ogg",
    "crit":            "res://assets/sfx/crit.ogg",
    "shield_hit":      "res://assets/sfx/shield_hit.ogg",
    "shield_break":    "res://assets/sfx/shield_break.ogg",
    "player_hurt":     "res://assets/sfx/player_hurt.ogg",
    "enemy_death":     "res://assets/sfx/enemy_death.ogg",
    "upgrade":         "res://assets/sfx/upgrade.ogg",
    "upgrade_select":  "res://assets/sfx/upgrade_select.ogg",
    "player_death":    "res://assets/sfx/player_death.ogg",
    "boss_appear":     "res://assets/sfx/boss_appear.ogg",
    "boss_death":      "res://assets/sfx/boss_death.ogg",
    "button_click":    "res://assets/sfx/button_click.ogg",
    "retreat_success": "res://assets/sfx/retreat_success.ogg",
}
```

### 音乐文件接入

编辑 `scripts/sound_manager.gd` 中的 `_get_music_path()` 方法：

```gdscript
func _get_music_path(music_name: String) -> String:
    match music_name:
        "menu":
            return "res://assets/music/menu.ogg"
        "battle":
            return "res://assets/music/battle.ogg"
        "battle_boss":
            return "res://assets/music/battle_boss.ogg"
        "base":
            return "res://assets/music/base.ogg"
        "settlement":
            return "res://assets/music/settlement.ogg"
        "race_select":
            return "res://assets/music/race_select.ogg"
    return ""
```

## 四、免费音效资源推荐

如需使用免费音效，可参考以下来源（需注明作者）：

### 音效
- **Freesound** (https://freesound.org) — 搜索 `laser`, `explosion`, `hit`, `ui click` 等关键词
- **Kenney.nl** — 免费的 UI 和游戏音效包

- **Incompetech** (https://incompetech.com) — Kevin MacLeod 免费音乐，按风格筛选
- **OpenGameArt** (https://opengameart.org) — 游戏专用免费音乐

> 注意：使用前请确认各网站的许可协议，确保符合项目用途（个人/商业）。

## 五、快速替换占位符（临时方案）

如果暂时没有音效文件，可以用 Godot 内置功能生成简单的程序化噪音作为占位：

1. 在 Godot 编辑器中右键 `assets/sfx/` → `Create New` → `AudioStreamWAV`
2. 设置 `Format` 为 `IMAGINARY`（生成静音占位）
3. 或使用在线工具生成短 `.ogg` 文件作为占位

后续有正式音效后直接替换文件路径即可。
