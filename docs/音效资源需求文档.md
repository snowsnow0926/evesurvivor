### 格式要求

- **格式**：`.ogg`（推荐）或 `.wav`
- **采样率**：44100 Hz
- **声道**：单声道（Mono）或立体声（Stereo）均可
- **位数深**：16-bit
- **时长**：尽量短（多数 < 0.5s），方便同时播放多个实例

### 音量参考

- 射击/命中等高频音效：建议 -3dB 到 0dB
- 爆炸/破碎等厚重音效：建议 -6dB 到 -3dB
- 背景触发音效（升级弹出）：建议 -6dB 到 -3dB
- 按钮点击：建议 -9dB 到 -6dB（不抢戏）

## 三、接入方法

### 生成后操作

1. 将 AI 生成的音效文件放入 `assets/sfx/` 目录，音乐文件放入 `assets/music/` 目录
2. 在 Godot 编辑器中刷新资源（右键项目 → 刷新）
3. 编辑 `scripts/sound_manager.gd`，在 `SFX_RESOURCES` 字典中填入文件路径
4. 如使用 `.ogg` 以外的格式（如 `.mp3`），确认 Godot 项目设置中已启用对应格式

### 音效文件接入

编辑 `scripts/sound_manager.gd`，在 `SFX_RESOURCES` 字典中填入文件路径：

```gdscript
const SFX_RESOURCES: Dictionary = {
    "shoot_missile":   "res://assets/sfx/shoot_missile.ogg",
    "shoot_cannon":    "res://assets/sfx/shoot_cannon.ogg",
    "shoot_railgun":   "res://assets/sfx/shoot_railgun.ogg",
    "shoot_laser":     "res://assets/sfx/shoot_laser.ogg",
    "hit":             "res://assets/sfx/hit.ogg",
    "crit":            "res://assets/sfx/crit.ogg",
    "shield_hit":      "res://assets/sfx/shield_hit.ogg",
    "shield_break":    "res://assets/sfx/shield_break.ogg",
    "player_hurt":     "res://assets/sfx/player_hurt.ogg",
    "enemy_death":     "res://assets/sfx/enemy_death.ogg",
    "upgrade":         "res://assets/sfx/upgrade.ogg",
    "upgrade_select":  "res://assets/sfx/upgrade_select.ogg",
    "player_death":    "res://assets/sfx/player_death.ogg",
    "boss_appear":     "res://assets/sfx/boss_appear.ogg",
    "boss_death":      "res://assets/sfx/boss_death.ogg",
    "button_click":    "res://assets/sfx/button_click.ogg",
    "retreat_success": "res://assets/sfx/retreat_success.ogg",
}
```

### 音乐文件接入

编辑 `scripts/sound_manager.gd` 中的 `_get_music_path()` 方法：

```gdscript
func _get_music_path(music_name: String) -> String:
    match music_name:
        "menu":
            return "res://assets/music/menu.ogg"
        "battle":
            return "res://assets/music/battle.ogg"
        "battle_boss":
            return "res://assets/music/battle_boss.ogg"
        "base":
            return "res://assets/music/base.ogg"
        "settlement":
            return "res://assets/music/settlement.ogg"
        "race_select":
            return "res://assets/music/race_select.ogg"
    return ""
```

## 五、AI 音效生成工作流

### 推荐流程

1. **按优先级生成** — 从 ★☆☆ 开始（`button_click`、`upgrade_select`、`hit`），快速产出
2. **同步生成** — 将同类型音效一起生成（如 4 种射击声一起给 prompt）
3. **逐个测试** — 放入 Godot 运行游戏，听效果再决定是否需要调整
4. **导出格式** — AI 生成后导出为 `.ogg`（推荐）或 `.wav`，统一放入 `assets/sfx/` / `assets/music/`
5. **填入路径** — 编辑 `sound_manager.gd` 中的 `SFX_RESOURCES` 字典

### 优先级建议

| 优先级 | 音效 | 理由 |
|--------|------|------|
| P0 | `button_click` | 全局 UI 交互反馈，频率最高 |
| P0 | `hit`、`enemy_death` | 战斗核心反馈 |
| P0 | `player_death` | 游戏结束体验 |
| P1 | `shoot_missile/cannon/laser/railgun` | 武器打击感 |
| P1 | `upgrade`、`upgrade_select` | 升级体验 |
| P1 | `shield_hit`、`shield_break` | 防御反馈 |
| P2 | `player_hurt` | 受伤反馈 |
| P2 | `boss_appear`、`boss_death` | BOSS 体验 |
| P2 | `crit` | 暴击爽感 |
| P2 | `retreat_success` | 撤离反馈 |
| P3 | 所有 BGM | 氛围音乐，优先级最低 |
| 可选 | `race_select` | 代码中尚未接入，可暂不生成 |
